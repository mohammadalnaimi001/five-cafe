# Five₅ Coffee — Souq Yard

موقع كافيه ثنائي اللغة (عربي/إنجليزي) مع نظام حجوزات بمخطط طاولات تفاعلي،
ولوحة تحكم منفصلة للأدمن. الباك إند Supabase — بدون سيرفر تديره أو تدفع فيه.

---

## الملفات

```
index.html            الموقع
admin.html            لوحة التحكم (صفحة منفصلة، لوجن منفصل)
config.js             ← الملف الوحيد اللي بتعدّله عشان تشغّله
assets/
  brand.css           الهوية البصرية (كريمي · أسود · ذهبي) — مشتركة بين الصفحتين
  i18n.js             كل النصوص عربي/إنجليزي في مكان واحد
  db.js               طبقة الداتا: Supabase أو وضع المعاينة
  site.js             منطق الموقع
  admin.js            منطق لوحة التحكم
supabase/
  schema.sql          الجداول والصلاحيات والدوال — انسخه والصقه مرة وحدة
```

بدون مكتبات خارجية ولا build step. `fetch` عادي، حجمها كلها أقل من ١٢٠ كيلوبايت.

## التشغيل — ٤ خطوات

### ١. أنشئ مشروع Supabase
[supabase.com](https://supabase.com) → **New project**. اختر منطقة قريبة
(Frankfurt أو London أقرب شي للأردن). الخطة المجانية بتكفي كافيه.

### ٢. شغّل السكيما
من لوحة Supabase: **SQL Editor → New query** → الصق كل محتوى
`supabase/schema.sql` → **Run**.

بينشئ الجداول، وصلاحيات الأمان (RLS)، والدوال الثلاث، وبيعبّي بيانات أولية
(٣ مناطق، ٢٦ طاولة، ١٤ صنف).

### ٣. حط المفاتيح في `config.js`
من **Project Settings → API** انسخ:

```js
SUPABASE_URL:      'https://xxxxx.supabase.co',
SUPABASE_ANON_KEY: 'eyJhbG...',
DEMO: false,          // ← الأهم: خلّيها false
```

> مفتاح `anon` عادي إنه يكون ظاهر بالمتصفح — هذا تصميمه. اللي بيحمي الداتا
> هو الـ RLS بملف `schema.sql`. **لا تحط `service_role` هون أبداً.**

### ٤. أنشئ مستخدم الأدمن
**Authentication → Users → Add user** → إيميل وباسورد.
هذا هو الدخول لـ `admin.html`. أضف مستخدم لكل موظف بدك يدخل عليها.

**ارفع الملفات** على أي استضافة ساكنة — Netlify، Vercel، Cloudflare Pages،
GitHub Pages، أو `public_html` على استضافتك العادية. ما في شي بدّه Node أو PHP.

## وضع المعاينة

`DEMO: true` (وهي القيمة الافتراضية) بتخلّي الموقع يشتغل كامل بدون أي باك إند —
البيانات بتتخزن بمتصفحك أنت فقط. استخدمها لتوريه للعميل قبل ما تعمل قاعدة البيانات.

بلوحة التحكم بوضع المعاينة: أي إيميل + باسورد من ٤ خانات بيفتحوا اللوحة،
وفي أزرار **بيانات تجريبية** و **مسح الحجوزات** للعرض.

## الأمان — كيف بتشتغل

| مين | بيقدر يشوف | بيقدر يعمل |
|---|---|---|
| زائر (anon) | القائمة، المناطق، الطاولات، الإعدادات | يعمل حجز عبر دالة `book_table` فقط |
| زائر (anon) | **ما بيقدر يقرأ جدول الحجوزات إطلاقاً** — لا أسماء ولا أرقام | — |
| موظف (مسجّل دخول) | كل شي | تأكيد/إلغاء/حذف، تعديل القائمة والطاولات والإعدادات |

الموقع بيعرف الطاولات الفاضية عن طريق دالة `availability_for` اللي بترجّع
"هذي الطاولة محجوزة: نعم/لا" وبس — بدون أي معلومة شخصية.

**الحجز محمي من التزاحم**: دالة `book_table` بتقفل صف الطاولة وبتتأكد إنها
فاضية جوّا نفس المعاملة، فلو ضغط زبونين على نفس الطاولة بنفس الثانية،
واحد بس بياخدها والثاني بيوصله `TABLE_TAKEN`.

## اللي تقدر تعدّله من لوحة التحكم

- **مخطط الطاولات** — اسحب الطاولة لمكانها بالمخطط، غيّر اسمها وعدد مقاعدها
  وشكلها، أضف أو احذف طاولات. السعة بتتحسب تلقائياً من مجموع المقاعد.
- **القائمة** — أضف صنف، عدّل الوصف، حط سعر (أو اتركه فاضي فيختفي من الموقع)،
  خبّي صنف عن الموقع، أو علّمه "الأكثر طلباً".
- **الإعدادات** — ساعات الفتح والإغلاق، الفاصل بين المواعيد، مدة حجز الطاولة،
  أقصى عدد أشخاص، وأرقام التواصل.

كل تعديل بيظهر على الموقع فوراً بدون ما تلمس أي ملف.

## نقاط لازم تتأكد منها مع صاحب المكان

هاي القيم افتراضية وأنا حطّيتها تخميناً — عدّلها قبل ما تنشر الموقع:

1. **وقت الفتح ١٠:٠٠ ص** — جوجل بيعطي وقت الإغلاق (١:٠٠ ص) بس. أكّد وقت الفتح.
2. **الطاولات وأماكنها** — ٢٦ طاولة (٤٢ + ٢٤ + ١٨ مقعد) ومواقعها بالمخطط
   تخمينية. رتّبها من تبويب "مخطط الطاولات" حسب المكان الحقيقي.
3. **الأسعار** — ما حطّيت أسعار عمداً. أضفها من تبويب "القائمة".
4. **مدة حجز الطاولة ٩٠ دقيقة** — عدّلها من الإعدادات لو سياستهم مختلفة.

المعلومات الثابتة (الاسم، العنوان، الهاتف ٠٧ ٩٢٢٢ ٥٠٥٩، التقييم ٤.٤ من ١١٠
مراجعة، والمراجعات الثلاث) كلها من ليستنج جوجل الحقيقي.

## أخطاء ممكن تشوفها

| الرسالة | معناها |
|---|---|
| `TABLE_TAKEN` | حدا حجز الطاولة قبله بثواني |
| `TABLE_TOO_SMALL` | عدد الأشخاص أكبر من مقاعد الطاولة |
| `NO_TABLE_FITS` | ما ضل طاولة تسع المجموعة بهذا الوقت |
| `INVALID_PHONE` | الرقم مش بصيغة `07xxxxxxxx` |
| `CLOSED_AT_THAT_TIME` | الوقت المطلوب برّا ساعات العمل |

كلها مترجمة للزائر بملف `assets/i18n.js` تحت `errors`.
